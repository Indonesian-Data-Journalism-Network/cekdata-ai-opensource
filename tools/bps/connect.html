Hubungkan data BPS

Masukkan API key BPS agar komputer ini dapat mengambil data langsung dari BPS. Kunci disimpan di komputer ini, bukan dikirim ke pengunjung website.

Belum punya kunci? Daftar atau masuk di portal Web API BPS, lalu daftarkan aplikasi Cek Data AI.

Pengambilan awal: kemiskinan, ketenagakerjaan, dan PDRB. Data akan diuji sebelum dipakai sebagai sumber jawaban.
