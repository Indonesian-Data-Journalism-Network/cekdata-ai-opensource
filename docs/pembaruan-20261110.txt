KODE DAN DATA BERBEDA
Kode tidak memuat API key, konfigurasi koneksi privat, database akun, koleksi
Qdrant, arsip unduhan, atau hasil chat pengguna. Server lain harus menyiapkan
data dan koneksinya sendiri. Mengambil commit ini tidak otomatis membuat isi
data server lain sama dengan komputer pengembangan.

General membaca konfigurasi Pinecone bila tersedia serta manifest BPS Qdrant
lokal bila tersedia. Pemilihan tabel dan seri berlaku pada keduanya; data
tumpang tindih tidak boleh dijumlahkan hanya karena berada di dua penyimpanan.
Bagian historis docs/bps-local.md yang menyebut publik masih memakai Pinecone
mencatat keadaan saat impor awal, bukan keadaan adapter General pada paket ini.
